// Architecture

Six AI Agents, One Shield

Each layer of the mesh has a specialized role. Together they form an autonomous defense pipeline.

LAYER 01
📡

Sentinel Mesh

Monitors network traffic, DOM mutations, script injections, and file system events to detect suspicious activity across multiple surfaces.

LAYER 02
🧠

Cognitive Triage

Maps threat events to MITRE ATT&CK techniques, builds a kill-chain narrative, and predicts the attacker's next moves.

LAYER 03
🔴

Red Agent

Simulates the attacker's perspective to find exploitable gaps and stress-test defenses before the threat fully materialises.

LAYER 04
🔵

Blue Agent

Generates prioritised countermeasures — blocking rules, isolation commands, patch recommendations — tailored to the specific attack.

LAYER 05
🕸️

Deception Weaver

Deploys dynamic honeypots and fake assets to lure, mislead, and gather intelligence on the attacker.

LAYER 06
🧬

Memory Crystallizer

Extracts a Threat DNA fingerprint from every incident and stores it locally so PHAGE gets smarter with every attack it sees.

// Quick Start

Up and Running in Minutes

PHAGE runs locally — no account, no cloud, no subscription required.

1

Download & Extract

Download the PHAGE package below and extract the folder to a permanent location on your machine.

2

Install Python Dependencies

Inside the project folder, run pip install -r requirements.txt to install all required libraries.

3

Configure Your API Key

Copy .env.example → .env and paste your OpenRouter or LLMs Factory API key.

4

Start the Local Server

Run python server.py to start the API server on localhost:8765.

5

Load the Chrome Extension

Open chrome://extensions, enable Developer Mode, click Load unpacked, and select the extension/ folder.

6

Click the PHAGE Icon & Scan

Navigate to any website, open the PHAGE popup, and click Scan Current Page — the AI mesh will do the rest.
